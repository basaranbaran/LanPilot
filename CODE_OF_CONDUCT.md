# Code of Conduct

## Our pledge

We want LanPilot to be a friendly, harassment-free space for everyone, regardless of experience level, background, identity or nationality.

## Expected behavior

- Be kind and respectful.
- Give and accept constructive feedback gracefully.
- Assume good intent, and ask when something is unclear.
- Focus on what is best for the project and the community.

## Unacceptable behavior

- Harassment, insults, discrimination or personal attacks.
- Trolling or deliberately derailing discussions.
- Publishing others' private information.
- Anything else that would be inappropriate in a professional setting.

## Enforcement

Maintainers may edit or remove comments, commits, issues and pull requests that break this code, and may block people who repeatedly do so.

To report a problem, contact the maintainer through their GitHub profile: https://github.com/basaranbaran

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
